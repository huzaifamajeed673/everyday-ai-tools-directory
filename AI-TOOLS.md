# Beginner-Friendly AI Tools Directory

A practical starting point for exploring AI tools for studying, writing, research, design, and productivity. Check each service's current pricing, privacy policy, and terms before using it.

## Writing and brainstorming
- [ChatGPT](https://chatgpt.com/) — brainstorm, explain concepts, and draft text.
- [Google Gemini](https://gemini.google.com/) — ask questions and explore ideas.
- [Claude](https://claude.ai/) — help with writing, analysis, and understanding long text.

## Research and learning
- [Perplexity](https://www.perplexity.ai/) — explore questions with linked sources; verify important claims.
- [NotebookLM](https://notebooklm.google.com/) — study and ask questions about sources you provide.
- [Khan Academy](https://www.khanacademy.org/) — learn academic subjects.

## Design
- [Canva](https://www.canva.com/) — create graphics, presentations, and social media designs.
- [Adobe Express](https://www.adobe.com/express/) — create and edit visual content.

## Coding
- [GitHub Copilot](https://github.com/features/copilot) — AI assistance for coding.
- [Google AI Studio](https://aistudio.google.com/) — experiment with AI models and developer tools.

## Tips for choosing AI tools
1. Start with one clear task.
2. Verify important facts because AI can make mistakes.
3. Protect passwords, private documents, and confidential information.
4. Check current prices and usage limits.
5. Use AI to support your own judgement.
